title: Order units with the right mouse button

targets:
- type: key
  id: ModernControls
  effect: added
credit:
- Joe
---

`ModernControls=yes` under `[Options]` in `sun.ini` moves orders to the right mouse button and leaves the left button to select, box-select and, on open ground, clear the selection. Coast scrolling on a right drag, the placement and mode buttons, the sidebar and the hotkeys are unchanged. The game controls dialog carries the switch as a Modern Controls check box.

The setting is off by default, so the classic layout remains exactly as before. It changes only which local button produces which order and touches no saved, recorded or networked state.
